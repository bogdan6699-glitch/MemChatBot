Aceeași bază de cunoștințe pentru tine și toți prietenii care folosesc site-ul.

Cum actualizezi regulamentul1. Deschide repository-ul proiectului pe GitHub.
2. Intră în folderul knowledge și deschide regulament.txt.
3. Apasă Edit, șterge textul demonstrativ și lipește regulamentul complet.
4. Apasă Commit changes. Vercel va publica automat versiunea nouă.
STOCARESERVER-SIDE

Regulamentul nu mai este salvat în browserul tău. Este citit de backend, astfel încât toți utilizatorii văd aceleași informații. Nu trebuie să îl încarce fiecare prieten separat.

Pentru modificări, actualizează fișierul din GitHub și așteaptă finalizarea redeploy-ului din Vercel. Nu pune cheia API în acest fișier.
